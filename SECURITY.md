# Security policy

WealthWise is an offline-first application. Financial records are stored
locally on the device; the app does not provide a cloud account or runtime
sync. Exported backups may be encrypted, but app data on the device is not
encrypted by that backup feature.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
private vulnerability reporting for this repository when available. Otherwise,
contact the repository maintainers privately through their GitHub profile.
Include a concise description, affected version, impact, and safe reproduction
details. Do not include real financial data, backup files, credentials, or
other private information.

Please allow maintainers time to investigate and coordinate a fix before
public disclosure.
