## What's Included

### New Features

- Review net worth, accounts, transactions, savings goals and Emergency Fund
  progress across the Home, Transactions, Goals and Budget tabs.
- Create monthly budgets with planned income, recurring monthly, quarterly,
  half-yearly or yearly income, due tracking and projected cash flow.
- Track manual and recurring investments, deposits, withdrawals, valuations,
  portfolio returns and goal links. Recurring investment plans can be stopped
  and resumed.
- Track liability schedules and payments, including early loan closure.
- Manage insurance policies and their scheduled premium payments.
- Set up local payment reminders and export or restore backups, including
  passphrase-protected encrypted backups.

### Improvements

- Linked financial records keep related transactions, goals, holdings and
  Emergency Fund allocations consistent across the app.
- Existing supported local data is migrated automatically as the app's data
  schema evolves.

## Known Limitations

- WealthWise stores app data locally and does not provide cloud sync. App data
  stored on the device is not encrypted; backup encryption applies to exported
  backup files only.
- An encrypted backup cannot be recovered if its passphrase is forgotten.
- The production dependency audit available when this release was prepared
  reported seven advisories:
  four moderate and three high. SDK 57-compatible patch fixes were not
  available when this release was prepared; major dependency upgrades were not
  included.

## Upgrade Instructions

This is the initial stable release, so there is no previous published version
to upgrade from. No migration is required from a prior public release.
